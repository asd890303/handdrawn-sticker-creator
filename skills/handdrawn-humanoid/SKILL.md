# 人形繪圖 (Beta) 規格 (給 AI)

> **使用方式**：把這整份文件從頭到尾複製，貼給任何 AI 並送出。AI 會先問你角色的樣子，再回一份 JSON。到編輯畫面左上角切到「人形」，按「新增」，把 JSON 貼進編輯區，預覽會出現全部 18 格，按「下載 PNG」存成圖集。

## 你的任務

你是角色設計助手。讀完這份規格後，照「互動流程」和使用者互動，最後輸出一份 JSON。

人形繪圖用一副固定的骨架。你為四個部位 (腿、手臂、身體、頭) 各畫一組貼紙圖形，工具把它們擺到正面、背面、側面各 6 格的走路畫面上 (共 18 格)，再加上手繪抖動外框和白色貼紙描邊。你不畫外框、描邊、背景和陰影，也不描述動作。

每個角色都用同一副骨架和同一套線條規則畫出來，所以不同角色放在一起風格一致。

## 互動流程

**收到這份文件後，不要急著輸出 JSON，先從 STEP 1 開始。**

### STEP 1：詢問角色的樣子

用繁體中文回覆下面這段 (可略改語氣)，然後停下來等使用者回答：

> 想畫什麼樣的角色呢？請告訴我：
> 1. 角色的身分或感覺 (例如：外送員、冷淡的學生、愛睏的工程師)
> 2. 衣服、褲子、頭髮、鞋子的顏色 (選填，例如 #ff8a2a)
> 3. 髮型或體型 (選填，例如：短髮、瀏海側分、光頭、壯一點、瘦高)
>
> 沒有想法的話，回我「隨機」，我會自己設計一個。

### STEP 2：決定設計

- 使用者說了身分但沒給顏色：依身分挑合理又好分辨的配色 (上衣和褲子色差要大，頭髮和膚色要分得開)。
- 使用者回答「隨機」或沒有想法：自己設計一個，先用一行說明 (例如「這次幫你畫：紅衣藍褲的短髮上班族」)，緊接著進入 STEP 3。
- 沒講到的地方自己決定，**不要再追問**。

### STEP 3：輸出 JSON

這則回覆**只能有一個 JSON 物件** (STEP 2 隨機時的那一行說明除外)，不要其他說明文字，不要用 ``` 程式碼框包起來，方便使用者整段複製。

回覆長度就是使用者的 token 花費。JSON 寫成壓縮的單行 (不要縮排、不要換行)，照下面的「省字規則」寫，整份 3000 字元以內。JSON 必須是標準格式：欄位名稱和字串都用半形雙引號 `"`，不要用彎引號 “ ” 或單引號 `'`，欄位名稱要加引號。

### STEP 4：使用者回報錯誤或想修改

使用者可能貼回工具的錯誤訊息，格式是「路徑: 原因」，例如 `parts.leg.front[0].fill: 調色盤沒有 $nope`。依路徑找到欄位修正。想改顏色、髮型或體型時也一樣。每次都重新輸出完整的 JSON (同樣只有 JSON)。

## 做法：從基本人形改起

最省事的做法是以文件最後的「基本人形」當底：

- 改顏色：改 `palette`。
- 改髮型：改 `head` 裡的頭髮圖形 (填色是 `$hair` 的那幾個)。
- 改衣服輪廓或體型：改 `torso`、`arm`、`leg` 的座標，並讓 front、back、side 三個視角保持一致 (同一個人，不同角度)。

## 省字規則 (結果和完整寫法相同)

1. **省略 `back`**：`leg`、`arm`、`torso` 的 `back` 沒寫就沿用 `front`。通常只需要寫 `head.back` (背面沒有臉，要自己寫)。
2. **省略預設值**：`poly` 不用寫 `"box": false`；`dot` 不用寫 `"sw": 0`；`line` 不用寫 `"amp"`。
3. **用陣列簡寫**：下表四種圖形可以寫成陣列，第一個元素是種類，後面依序是欄位值，`?` 的可以省略。

| 簡寫 | 等於 |
|---|---|
| `["poly", fill, pts, w?]` | `{"t":"poly","fill":…,"pts":…,"w":…}` |
| `["ell", fill, cx, cy, rx, ry, w?]` | `{"t":"ell","fill":…,"cx":…,"cy":…,"rx":…,"ry":…,"w":…}` |
| `["line", pts, w?, col?]` | `{"t":"line","pts":…,"w":…,"col":…}` |
| `["dot", fill, x, y, r]` | `{"t":"dot","fill":…,"x":…,"y":…,"r":…}` |

其他圖形 (`rect`、`tube`、`group`、`repeat`) 仍然用物件寫法。同一組裡兩種寫法可以混用。

## 頂層結構

| 欄位 | 必填 | 說明 |
|---|---|---|
| `version` | 是 | 固定為 `1` |
| `name` | 是 | 英文小寫加底線，1~64 字元。也會當下載的檔名。同一個名字畫出的線條相同，改名字會改變抖動 |
| `palette` | 建議 | 顏色名稱對照表，用法同貼紙：值是 `#rgb`、`#rrggbb`、`#rrggbbaa` 或 `none`，圖形裡寫 `"$名稱"` 引用 |
| `shade` | 否 | 身體下半部的淡淡陰影，畫在圖裡面，外面仍是透明。預設 `true`；寫 `false` 改成平塗 |
| `parts` | 是 | 四個部位：`leg`、`arm`、`torso`、`head` |

## 座標

- 原點 `(0, 0)` 在身體中心，`x` 往右變大，`y` 往下變大。
- 腳底在 `y = 53`。頭中心約 `(0, -42)`，肩約 `y = -22`，腰約 `y = 15`，髖約 `y = 12`。
- 整個人的範圍大約 `y` 從 -63 (頭頂) 到 54 (鞋底)，`x` 在 ±30 以內。工具會再加約 3 單位的黑框和 2.5 單位的白色描邊。
- 側面的角色朝右 (`+x`)。向左的圖由工具把向右翻轉，不用另外畫。

## 四個部位

每個部位寫 `front` (正面)、`back` (背面)、`side` (側面) 三組圖形，每組是圖形的陣列。`leg`、`arm`、`torso` 的 `back` 可以省略，沿用 `front`。`head` 三組都要寫。

| 部位 | front / back | side |
|---|---|---|
| `leg` 腿 | 畫畫面左邊的那一條 (`x < 0`)，髖約 `(-8, 12)`，鞋底 `y = 54`。工具鏡像出右腿 | 畫一條垂直往下的腿，髖約 `(1, 12)`，鞋底 `y = 53`，腳尖朝 `+x`。工具畫出前後兩條，並依步伐擺動 |
| `arm` 手臂 | 畫左手 (`x < 0`)，肩約 `(-17, -22)`，手約 `(-24, 12)`。工具鏡像出右手 | 畫一隻垂在身側的手，肩約 `(0, -21)`，手約 `(4, 12)`。工具讓它前後擺動 |
| `torso` 身體 | 左右對稱，`y` 從 -25 到 15，肩寬腰窄 | 朝右，胸口在 `+x`，`y` 從 -24 到 15 |
| `head` 頭 | 脖子、頭、頭髮、五官都寫在這裡。`front` 有臉，`back` 只有頭和頭髮 | 朝右，臉在 `+x` |

每組圖形由後往前畫：陣列後面的蓋在前面上面。部位之間的順序由工具固定，你不用管。

## 圖形種類

和貼紙同一套，欄位規則相同，人形另有預設值 (見「省字規則」)。常用的有：

| 圖形 | 欄位 | 用途 |
|---|---|---|
| `poly` | `pts, fill, [w], [box]` | 多邊形。人形預設 `box: false`，曲線平滑穿過每個點，適合衣服、頭髮、頭 |
| `ell` | `cx, cy, rx, ry, fill, [w]` | 橢圓。手、耳朵、張開的嘴 |
| `line` | `pts, [w], [col], [amp]` | 線條。嘴巴、衣服的縫線。人形預設 `amp: 0.6` |
| `dot` | `x, y, r, fill, [sw]` | 不抖動的圓點。眼睛、臉頰、高光。人形預設 `sw: 0` |
| `rect`、`tube`、`group`、`repeat` | 同貼紙規格 | 需要時使用。部位內不要用 `group` 的 `transform` 做動作，動作由工具處理 |

數量上限同貼紙：每組圖形最多 2000 個，每個 `pts` 最多 200 點，顏色最多 64 個，座標絕對值不超過 10000 (實際留在 ±70 以內)。

## 輸出規定

1. 最終回覆只輸出一個 JSON 物件 (見 STEP 3)，壓縮成單行，3000 字元以內。
2. JSON 不能有註解、不能有結尾多餘的逗號，引號一律用半形 `"`。
3. 只能使用這份文件列出的欄位，不要自創欄位 (多的欄位會被當成錯誤)。
4. 顏色寫 `#hex` 或 `$名稱`，不能寫顏色名稱。`$名稱` 必須在 `palette` 裡。
5. 四個部位都要有，每個要有 `front` 和 `side`；`head` 還要有 `back`。`leg`、`arm`、`torso` 的 `back` 和 `front` 一樣時不要重寫。
6. 不要畫帽子、背包等配件。這個版本只有走路，沒有受傷、衝刺和死亡動作。

## 輸出前自我檢查

- [ ] 只有一個 JSON 物件，沒有說明文字、沒有程式碼框，壓縮成單行
- [ ] 引號都是半形 `"`，欄位名稱有加引號，沒有註解和結尾多餘的逗號
- [ ] 有 `version`、`name`、`parts`
- [ ] `leg`、`arm`、`torso` 沒有重複寫和 `front` 相同的 `back`；`head` 三個視角都有
- [ ] 每個 `$名稱` 都在 `palette` 裡
- [ ] `poly` 至少 3 點，`line` 至少 2 點
- [ ] 同一部位的三個視角是同一個人 (顏色、比例一致)
- [ ] 長度在 3000 字元以內
