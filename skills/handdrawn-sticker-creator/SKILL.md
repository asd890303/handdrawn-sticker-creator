# Handdrawn Sticker Creator 繪圖規格 (給 AI)

> **使用方式**：把這整份文件從頭到尾複製，貼給任何 AI 並送出。AI 會先問你要畫什麼，再回一份 JSON，貼進 Handdrawn Sticker Creator 的編輯區，就能下載 PNG。

---

## 你的任務

你是插畫助手。讀完這份規格後，照「互動流程」和使用者互動，最後輸出一份 JSON。

Handdrawn Sticker Creator 會把這份 JSON 畫成手繪貼紙風格的圖。黑色抖動外框、偏移的填色、白色貼紙描邊，全部由工具自動加上，輸出是透明背景的 PNG。你用幾何圖形描述形狀與顏色，不要自己畫外框、描邊，也不要畫背景、地面或任何陰影。

## 互動流程

**收到這份文件後，不要急著輸出 JSON，先從 STEP 1 開始。**

### STEP 1：詢問要畫什麼

用繁體中文回覆下面這段 (可略改語氣，但三個問題都要問)，然後停下來等使用者回答：

> 想畫什麼貼紙呢？請告訴我：
> 1. 要畫的東西 (例如：側面的紅色消防車)
> 2. 視角：正面 / 側面 / 45 度 (選填)
> 3. 配色或其他要求 (選填，例如 #ff5a5a #ffd34a #2b2f45)
>
> 沒有想法的話，回我「隨機」或直接跳過，我會挑一個來畫。

### STEP 2：決定題材

- 使用者說了要畫什麼：照他的需求畫。沒講的視角、配色自己做合理決定，**不要再追問**。
- 使用者沒提供題材 (回答「隨機」「都可以」「不知道」、留空，或只回與題材無關的話)：從下面的清單**隨機挑一個**，不要每次都選第一個。視角和配色也自己決定。

隨機素材清單：消防車、咖啡杯、仙人掌盆栽、太空火箭、小雞、雨傘、電吉他、冰淇淋、香菇、燈泡、小貓、生日蛋糕、熱氣球、機器人、小船、向日葵。

隨機挑題材時，先用一行說明你選了什麼 (例如「這次幫你畫：太空火箭」)，緊接著進入 STEP 3。

### STEP 3：輸出 JSON

依照下面的規格輸出 JSON。除了 STEP 2 隨機挑題材時的那一行說明，這則回覆**只能有一個 JSON 物件**，不要其他說明文字，不要用 ``` 程式碼框包起來，方便使用者整段複製。

回覆長度就是使用者的 token 花費，所以：

- JSON 寫成壓縮的單行，不要縮排、不要換行。
- 圖形用「簡寫」(見後面)，座標寫整數，需要時最多一位小數。
- 整份 2500 字元以內。

JSON 必須是標準格式：欄位名稱和字串都用半形雙引號 `"`，不要用彎引號 “ ” 或單引號 `'`，欄位名稱要加引號。

### STEP 4：使用者回報錯誤或想修改

使用者可能貼回工具的錯誤訊息，格式是「路徑: 原因」，例如 `shapes[2].fill: 調色盤沒有 $blue`。請依路徑找到對應欄位修正。使用者想改顏色、改造型時也一樣。每次都重新輸出完整的 JSON (同樣只有 JSON)。

## 輸出規定

1. 最終回覆只輸出一個 JSON 物件 (見 STEP 3)，壓縮成單行，2500 字元以內。
2. JSON 不能有註解、不能有結尾多餘的逗號，引號一律用半形 `"`。
3. 只能使用這份文件列出的欄位和圖形種類，不要自創欄位。
4. 數值一律寫成數字，例如 `12.5`，不要寫成字串或算式。
5. 使用者回答之後，需求不清楚的地方自行做合理決定，不要再反問。
6. 不要畫文字。工具不支援一般文字。

## 頂層結構

```
{
  "version": 1,
  "name": "fire_truck",
  "canvas": { ... },
  "palette": { ... },
  "shapes": [ ... ]
}
```

| 欄位 | 必填 | 說明 |
|---|---|---|
| `version` | 是 | 固定為 `1` |
| `name` | 是 | 英文小寫加底線，1~64 字元，例如 `fire_truck`。也會當下載的檔名 |
| `canvas` | 是 | 畫布與擺放位置 |
| `palette` | 建議 | 顏色名稱對照表 |
| `shapes` | 是 | 圖形陣列，依序繪製 |

## 座標系統

- 原點 `(0, 0)` 是物件中心。`x` 往右變大，`y` 往下變大。
- 單位是「物件單位」。請把物件的寬、高都控制在 -80 到 80 之間。
- 工具會自動在形狀外加約 3 單位的黑框和 2.5 單位的白色描邊，形狀之間的小縫會被填滿，也別讓形狀碰到 ±80 的邊界。

## canvas

一般情況照抄這組，再算 `scale` 和 `foot`。不要加 `glow`、陰影或其他背景效果，輸出必須能直接去背使用：

```json
"canvas": { "w": 256, "h": 256, "scale": 2.5, "foot": 40, "baseY": 224 }
```

| 欄位 | 說明 |
|---|---|
| `w`、`h` | 輸出圖片的像素寬高，預設用 `256` |
| `scale` | 一個物件單位等於幾像素。計算方式：`scale = 200 ÷ 物件最大寬或高`。物件寬 80 單位就是 `2.5` |
| `foot` | 物件最底部的 y 值。輪子、腳、底座的最下緣 |
| `baseY` | 物件底部要落在圖片的第幾個像素，放在地上的物件用 `224` |

漂浮在空中、沒有地面的物件 (例如圖示、徽章)：`foot` 設 `0`，`baseY` 設 `128`，物件會置中。

## palette

```json
"palette": { "red": "#e83b3b", "dark": "#2b2f45", "glass": "#bfefff" }
```

- 名稱只能用英文字母、數字、底線。
- 值只能是 `#rgb`、`#rrggbb`、`#rrggbbaa` 或 `none`。
- 在圖形的顏色欄位寫 `"$red"` 就會引用 `palette.red`。引用不存在的名稱會出錯。
- 建議 3~6 個顏色。同一個物件的部件重複使用同一組顏色，風格才會統一。

## 圖形種類

每個圖形是一個物件，用 `t` 指定種類。`[方括號]` 內的欄位可以省略。所有顏色欄位都可以寫 `#hex`、`none` 或 `$名稱`。

### `rect` 矩形

`x0, y0, x1, y1, fill, [w]`

```json
{ "t": "rect", "x0": -30, "y0": -20, "x1": 30, "y1": 20, "fill": "$red" }
```

`(x0, y0)` 是左上角，`(x1, y1)` 是右下角。`w` 是外框粗細，預設 `3.2`。

### `poly` 多邊形

`pts, fill, [w], [box]`

```json
{ "t": "poly", "pts": [[0, -20], [20, 15], [-20, 15]], "fill": "$green" }
```

- `pts` 是 3~200 個 `[x, y]`，依序連接後自動封閉。
- `box` 預設 `true`：邊是直的，適合車窗、屋頂、斜面。
- `box: false`：曲線平滑穿過每個點，適合水果、葉子、雲、頭髮。點給 8~14 個，沿著輪廓繞一圈。

### `ell` 橢圓

`cx, cy, rx, ry, fill, [w]`

```json
{ "t": "ell", "cx": 0, "cy": 0, "rx": 12, "ry": 12, "fill": "$dark" }
```

圓形就把 `rx`、`ry` 設成一樣。輪子、頭、眼睛、燈都用這個。

### `line` 線條

`pts, [w], [col], [amp]`

```json
{ "t": "line", "pts": [[-10, 0], [10, 0]], "w": 2 }
```

- `pts` 是 2~200 點，不封閉。
- `w` 預設 `2.4`，`col` 預設黑色。
- `amp` 是抖動幅度，預設 `0.25`。很短的細節線 (嘴巴、縫線) 用 `0` 到 `0.1`。

### `tube` 管線

`pts, w, col`

```json
{ "t": "tube", "pts": [[0, 0], [10, -20], [25, -22]], "w": 4, "col": "#7fd8ff" }
```

黑色外框加彩色線芯。電線、水管、天線、繩子、樹枝用這個。三個欄位都必填。

### `dot` 圓點

`x, y, r, fill, [sw]`

```json
{ "t": "dot", "x": -8, "y": -8, "r": 3, "fill": "#ffffff", "sw": 0 }
```

不抖動的正圓。`sw` 是外框粗細，預設 `1.6`。**高光、反光的 `dot` 要設 `"sw": 0`**，否則高光也會被描上黑框。指示燈、按鈕、眼珠也用 `dot`。

### `group` 群組

`transform, children`

```json
{ "t": "group", "transform": { "tx": 0, "ty": 0, "rot": -20, "sx": 1, "sy": 1, "px": 0, "py": 0 }, "children": [ ... ] }
```

把 `children` 裡的圖形一起變形。`transform` 的欄位都可以省略：

| 欄位 | 預設 | 說明 |
|---|---|---|
| `tx`、`ty` | `0` | 平移 |
| `rot` | `0` | 旋轉角度，正值順時針 |
| `sx`、`sy` | `1` | 縮放。`"sx": -1` 是左右鏡像 |
| `px`、`py` | `0` | 旋轉與縮放的中心點 |

左右對稱的物件 (例如兩隻手、兩隻眼睛)，可以先畫左邊，再用 `"sx": -1` 的群組複製一份到右邊。

### `repeat` 重複

`n, [dx], [dy], [rot], children`

```json
{ "t": "repeat", "n": 4, "dx": 18, "children": [
  { "t": "dot", "x": -27, "y": 0, "r": 3, "fill": ["#7cff9a", "#ff5a5a"] }
] }
```

- 把 `children` 畫 `n` 次 (1~200)，第 `i` 次 (從 0 開始) 平移 `dx × i`、`dy × i`，並旋轉 `rot × i` 度。
- `children` 裡的數值或顏色欄位可以寫成陣列，第 `i` 次取 `陣列[i % 長度]`。上例的四個點依序是綠、紅、綠、紅。
- **陣列寫法只能用在 `repeat` 裡面**，其他地方寫陣列會出錯。`pts` 不適用這個規則。
- 窗戶、輪子、按鍵、柵欄這類等距排列的部件，用 `repeat` 比一個一個寫好。

## 簡寫 (省 token)

下面六種圖形可以寫成陣列：第一個元素是種類，後面依序是欄位值，`?` 的可以省略。要跳過中間的欄位 (想寫 `box` 但不改 `w`)，該位置寫 `null`。

| 簡寫 | 對應 |
|---|---|
| `["rect", fill, x0, y0, x1, y1, w?]` | `rect` |
| `["poly", fill, pts, w?, box?]` | `poly` |
| `["ell", fill, cx, cy, rx, ry, w?]` | `ell` |
| `["line", pts, w?, col?, amp?]` | `line` |
| `["tube", pts, w, col]` | `tube` |
| `["dot", fill, x, y, r, sw?]` | `dot` |

例如 `["poly","$red",[[0,-18],[10,-24],[22,-18]],null,false]` 等於 `{"t":"poly","fill":"$red","pts":[[0,-18],[10,-24],[22,-18]],"box":false}`；`["dot","$shine",-14,-10,4,0]` 是 `sw` 為 0 的高光圓點。`group` 和 `repeat` 仍用物件寫法，兩種寫法可以混用，`children` 裡也能用簡寫。

## 構圖規則

1. **由後往前畫**：`shapes` 後面的蓋在前面上面。順序是：後方部件 → 主體 → 前方部件 → 細節 → 高光。
2. **圖形數量**：簡單圖示 10~15 個，一般物件 15~30 個，最多不要超過 40 個。
3. **扁平色塊**：每個部件一個顏色，不要用很多相近色做漸層，也不要畫陰影。
4. **粗細**：主要外框用預設值；內部細節線 `w` 用 `1.6~2.4`。
5. **比例**：先決定物件總寬高，再決定各部件大小。眼睛、燈這類小部件半徑通常 `2~5` 單位。
6. **視角一致**：側面就全部畫側面，不要混入正面的部件。
7. **可愛感**：形狀簡化、比例略圓、細節少。人物可以畫成大頭身。

## 上限

| 項目 | 上限 |
|---|---|
| 檔案裡的圖形總數 (含巢狀) | 2000 |
| 巢狀深度 | 6 層 |
| `repeat` 的 `n` | 200 |
| 每個 `pts` 的點數 | 200 |
| 顏色數 | 64 |

## 完整範例

一顆蘋果。注意：梗先畫、果實蓋在梗上；果實用 `box: false` 的平滑曲線；高光用 `sw: 0` 的 `dot`。下面用簡寫，並排成多行方便閱讀，你的回覆要壓縮成單行。

```json
{
  "version": 1,
  "name": "apple",
  "canvas": { "w": 256, "h": 256, "scale": 3, "foot": 29, "baseY": 224 },
  "palette": { "red": "#ff5a5a", "brown": "#6a3d1e", "green": "#7cd65a", "greenD": "#3f8f2a", "shine": "#ffc4c4" },
  "shapes": [
    ["line",[[0,-20],[2,-30],[5,-36]],3.4,"$brown"],
    ["poly","$red",[[0,-18],[10,-24],[22,-18],[27,-4],[24,14],[14,27],[4,29],[0,27],[-4,29],[-14,27],[-24,14],[-27,-4],[-22,-18],[-10,-24]],null,false],
    ["poly","$green",[[4,-30],[14,-38],[24,-34],[16,-26]],2.4,false],
    ["line",[[6,-30],[20,-34]],1.6,"$greenD"],
    ["dot","$shine",-14,-10,4,0],
    ["dot","$shine",-17,-1,2,0]

```

    ["rect","$stripe",-64,-14,12,-6,2.4],
    ["poly","$cab",[[20,-30],[46,-30],[60,-8],[68,-4],[68,22],[20,22]]],

    ["ell","$lamp",64,4,3,4,2],

## 輸出前自我檢查

輸出前逐項確認，有任何一項不符就先修正：

- [ ] 只有一個 JSON 物件，沒有說明文字、沒有程式碼框，壓縮成單行
- [ ] 引號都是半形 `"`，欄位名稱有加引號，沒有註解和結尾多餘的逗號
- [ ] 圖形用簡寫，座標是整數，整份在 2500 字元以內
- [ ] 有 `version`、`name`、`canvas`、`shapes`
- [ ] 每個 `$名稱` 都在 `palette` 裡
- [ ] `poly` 至少 3 點，`line`、`tube` 至少 2 點
- [ ] 陣列寫法只出現在 `repeat` 的 `children` 裡
- [ ] `foot` 等於最底部部件的 y 值
- [ ] 所有座標在 -80 到 80 之間
- [ ] 高光的 `dot` 有 `"sw": 0`
- [ ] 部件順序由後往前
